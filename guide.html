📜 Описание скриптов

01_inn_validation.py Готов

Назначение: Очистка, проверка длины и контрольной суммы по алгоритму ФНС, классификация (ЮЛ/ИП/ФЛ).

Вход: data/input/*.csv (1 столбец с ИНН)

Выход: data/output/01_validated_inn.csv

Команда:

python scripts/01_inn_validation.py

02_egrul_retry_final.py Готов

Назначение: Массовое скачивание подписанных PDF-выписок ЕГРЮЛ/ЕГРИП с egrul.nalog.ru. Поддерживает ретраи, ротацию сессий, экспоненциальные задержки и безопасное прерывание.

Вход: data/output/01_validated_inn.csv

Выход: data/output/02_egrul_parsed.csv + data/output/pdfs/egrul_*.pdf

Команда:

python scripts/02_egrul_retry_final.py

generate_report.py Готов

Назначение: Генерация интерактивного HTML-отчёта с фильтрами, поиском и ссылками на скачанные PDF.

Вход: data/output/02_egrul_parsed.csv

Выход: data/output/report_egrul.html

Команда:

python scripts/generate_report.py

🚀 Быстрый запуск

  1. Установи зависимости: 
    pip install pandas requests
  2. Подготовь структуру: 
    mkdir -p data/input data/output/pdfs
  3. Запусти пайплайн последовательно: 
    python scripts/01_inn_validation.py
python scripts/02_egrul_retry_final.py
python scripts/generate_report.py
  4. Открой отчёт: 
    start data/output/report_egrul.html  # Windows
xdg-open data/output/report_egrul.html # Linux
open data/output/report_egrul.html     # macOS

⚠️ Важные примечания

  • Не открывай 02_egrul_parsed.csv в Excel во время работы скрипта. Windows блокирует файл, что вызывает PermissionError.
  • Прогресс сохраняется автоматически. При прерывании (Ctrl+C) или сбое просто перезапусти скрипт. Уже скачанные PDF будут пропущены.
  • Анти-бот защита ФНС: При массовых запросах возможны 400/429 или требование CAPTCHA. Скрипт обрабатывает это через задержки и ротацию сессий. Для полного покрытия >95% рекомендуется запускать ночью или разбить на batches по 100 ИНН.
  • Версия Python: Требуется 3.10+ для стабильной работы pandas и requests.
