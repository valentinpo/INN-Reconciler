# 🔍 INN Reconciler

Инструмент для автоматической валидации ИНН и сопоставления организаций с данными ЕГРЮЛ (egrul.nalog.ru). Загружает официальные выписки, разбирает их и формирует HTML-отчёты.

## 🎯 Что решает

При ручной сверке контрагентов по ИНН много времени уходит на открытие каждой выписки ЕГРЮЛ по отдельности. Этот инструмент автоматизирует цикл:

1. **Валидация ИНН** — проверка корректности по контрольному числу
2. **Запрос выписки ЕГРЮЛ** — скачивание официального документа по ИНН с egrul.nalog.ru
3. **Разбор и сопоставление** — извлечение названия и статуса организации из выписки
4. **Формирование отчёта** — сбор результатов в единый HTML-файл со ссылками на PDF

## 📁 Структура

```
INN_Reconciler/
├── scripts/                     # Скрипты (очередность по номерам)
│   ├── 01_inn_validation.py     # Проверка ИНН из CSV
│   ├── 02_egrul_retry.py        # Загрузка выписок ЕГРЮЛ
│   ├── 02_egrul_retry_final.py  # Финальная версия загрузки с повторами
│   ├── generate_report.py       # Формирование отчёта (v1)
│   ├── generate_report_v2.py    # Формирование отчёта (HTML + ссылки на PDF)
│   └── test_egrul_mini.py       # Мини-тест загрузки выписок
├── guide.html                   # Справочное руководство
└── README.md
```

## 🚀 Использование

```bash
# 1. Валидация ИНН из списка
python scripts/01_inn_validation.py

# 2. Загрузка выписок ЕГРЮЛ по валидным ИНН
python scripts/02_egrul_retry_final.py

# 3. Генерация отчёта
python scripts/generate_report_v2.py
```

### Зависимости

- Python 3.8+
- `pandas`, `requests`

```bash
pip install pandas requests
```

## ⚠️ Примечание

- Скрипты обращаются к открытому сервису **egrul.nalog.ru**. Соблюдайте разумную задержку между запросами (по умолчанию ~4.5 сек), чтобы не создавать нагрузку.
- Результаты (PDF-выписки, отчёты, CSV) сохраняются в `data/output/` и не включены в репозиторий.
